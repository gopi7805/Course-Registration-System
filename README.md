
# Course Registration System

## About the Project
A Full Stack web application that allows students to view available courses and register for courses.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- HTML
- CSS
- JavaScript
- Postman

## Features
- View available courses.
- Register for courses.
- Manage course details.
- Perform CRUD operations.
- Store application data using MySQL.

## Backend
- RESTful API development
- Spring Data JPA
- Database integration

## Frontend

- JavaScript
